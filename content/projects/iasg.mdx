## Overview

IASG Cooperative is a savings and loans platform serving members across five affiliated
companies: Interguide Air, Interguide Academy, Sabre Travel Network, Wisefair, and GolfView.
It is **live in production** with a public API and Swagger docs.

## What I built

- **Member flows**: signup with admin approval, savings accounts with Flutterwave-backed
  deposits, loan applications with guarantor sign-off, and repayment (manual or monthly
  salary-deduction batches).
- **Money movement**: dividend crediting, real-time transaction notifications, and member
  statement generation as PDF and CSV.
- **Admin portal** for staff to run verification, approvals, disbursement, and configuration.
- Rate limiting, login-lockout protection, and a documented OpenAPI schema.

## Stack

Django 5.2 with Django REST Framework, JWT auth, serverless Neon Postgres, Celery,
Flutterwave for payments and BVN verification, Resend for email, Cloudinary for uploads,
and drf-spectacular for OpenAPI. Deployed on Vercel.

## Proof

The backend is live at the link above, and the Swagger UI is public: it shows the full API
surface with no login required. The screenshots are the cooperative interface in use.
