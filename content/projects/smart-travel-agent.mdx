## Overview

Smart Travel Agent is an autonomous AI agent for travel: it searches flights, monitors
prices, and answers questions about uploaded documents. It plans multi-step tasks and
decides which tool to use for each.

## What I built

- A **LangChain agent** that chooses tools (flight search, weather, booking) based on the
  request, with live-API data and a simulated fallback.
- **Background price monitoring** for saved bookings.
- **Document Q&A**: upload a PDF, ask questions, get answers from a vector store.
- A **multi-agent mode** (CrewAI) where four specialized agents collaborate on a request.
- A FastAPI backend with an OpenAPI surface and a Streamlit UI.

## Proof

In a real run, I asked the agent to find flights. It called the flight-search tool, got the
data back, and then **reasoned about a mismatch** in the tool's output (the results were for
the wrong origin airport), flagged it, and offered to retry. That is genuine agentic behavior:
tool use plus validation of the result, not a scripted happy path.
